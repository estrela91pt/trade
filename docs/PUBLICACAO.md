# Checklist de publicação

- [ ] Confirmar funcionamento local e executar testes.
- [ ] Configurar domínio e HTTPS.
- [ ] Configurar segredos e chaves API no servidor.
- [ ] Confirmar cobertura, limites, custos e licenças dos fornecedores de dados.
- [ ] Configurar base de dados persistente e backups.
- [ ] Testar restauro dos backups.
- [ ] Ativar logs, métricas e alertas.
- [ ] Publicar termos, política de privacidade e contacto de suporte.
- [ ] Definir processos RGPD para acesso, correção, exportação e apagamento.
- [ ] Testar pagamentos em ambiente sandbox.
- [ ] Fazer testes de segurança, carga e regressão.
- [ ] Validar a interface em telemóvel e computador.
- [ ] Fazer lançamento gradual e acompanhar erros.

Não anunciar a plataforma como modelo preditivo validado sem resultados históricos reproduzíveis.
